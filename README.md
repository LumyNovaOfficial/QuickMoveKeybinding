# QuickMoveKeybinding

A lightweight mod that allows you to customize the quick move keybind (normally Shift), giving you full control over inventory interactions. The mod provides clear instructions on how to change the keybind directly in the code or through the keybind settings, so you can easily configure the action to your preference.

## Features
- Change the quick move keybind to any key you prefer
- Clear instructions provided for configuring the keybind
- Works seamlessly with vanilla inventory and other mods
- Lightweight and client-side only

## Installation
1. Make sure you have Fabric Loader installed.
2. Place `QuickMoveKeybinding` in your `mods` folder.
3. Start Minecraft and configure the keybind in Controls, following the included instructions.

## Compatibility
- Minecraft 1.17 – 1.21.11
- Fabric Loader
- Works with most mods that do not override inventory behavior
